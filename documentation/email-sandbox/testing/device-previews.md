# Device Previews (coming soon)

Preview on Devices renders any captured email across a catalog of real email clients and devices - Gmail, Outlook, Apple Mail, mobile clients, and more - so you can see exactly how your HTML will look before you send to real recipients. Pick which clients you want, kick off a preview, and Mailtrap returns a screenshot per client within about a minute.
